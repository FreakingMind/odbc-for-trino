The Trino ODBC driver is installed

1. Create a data source. Open Applications → iODBC → iODBC Administrator64, tab System DSN → Add → Trino ODBC. Enter a name (e.g. Trino) and add these keywords with + (double-click a cell to edit it):

hostname    https://trino.example.com
port        443
authmethod  External Auth
catalog     iceberg      (optional)
schema      sales        (optional)

2. Use it in Excel. Data → Get Data → From Database (Microsoft Query) → tab System DSN → your data source. Leave the login fields empty; External Auth opens a browser to sign in. Write table names in full: catalog.schema.table.

Cyrillic and other non-Latin text: set Excel's language to that language in System Settings → General → Language & Region → Applications. The system language can stay as it is.

More options and help: the project README. To remove the driver: sudo /Library/ODBC/TrinoODBC/uninstall.sh
